# Angry Judge: The Short Rant Contest

A tiny Python program (stdlib only) that writes one original short rant to
`/output/entry.txt`: a furious, funny complaint about a smoke detector that
only ever chirps at 3 a.m.

Run it with `python3 main.py` (or set `OUTPUT_PATH` to choose where the
rant is written). The rant is 1–400 characters of UTF-8 text, per the
competition gate.
